Проект и код

DVB Backend ↗

Python / Django

REST API и бизнес-логика системы управления автосервисом.

  • Django REST Framework, собственная модель пользователя, JWT и permissions для разграничения доступа.
  • PostgreSQL и Django ORM: связи между заказами, услугами, сотрудниками, филиалами и автомобилями.
  • ASGI, WebSocket и Redis для уведомлений; фильтрация данных и журналирование операций.
  • Backend-тесты, нагрузочные сценарии Locust, Dockerfile и Docker Compose для воспроизводимого запуска.

DVB Frontend ↗

Vue 3 / JavaScript

SPA для клиентов и сотрудников с адаптивными пользовательскими и административными интерфейсами.

  • Vue Router с защищёнными маршрутами, Pinia для авторизации и Axios для работы с REST API.
  • Онлайн-запись, профиль, автомобили пользователя, история и статусы заказов, realtime-уведомления.
  • Административная панель с CRUD-разделами и визуализацией статистики через Chart.js.
  • E2E-сценарии Playwright для авторизации, записи, профиля, навигации и административных функций; запуск в GitHub Actions.
